# TechNova AI Internship – AI Chatbot

## 📌 Project Overview

This project focuses on developing an AI chatbot with an interactive web interface. It was created as part of the TechNova AI Internship to explore chatbot development and web application integration.

The project includes an HTML-based user interface and is intended to connect with a Python backend for processing user messages.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/surya29916/TechNova-AI-Chatbot.git
cd TechNova-AI-Chatbot
```

### 2. Install Dependencies

If a `requirements.txt` file is available, run:

```bash
pip install -r requirements.txt
```

Otherwise, install the packages required by your project.

### 3. Run the Application

If your project includes a Flask backend named `app.py`, run:

```bash
python app.py
```

Open the local URL displayed in the terminal to access the chatbot.
